# Pulse Dashboard

Pulse is a team and project activity dashboard built with React, TypeScript, and Vite. It provides visibility into ongoing sprints, project statuses, team member workload, and team activities.

## Features

- **Project Tracking**: Overview of active, planned, and completed team projects with health indicators.
- **Activity Stream**: Log of recent team updates, pull requests, deployments, and task completions.
- **Team Overview**: Quick status and workload indicators for team members.
- **Metrics Summary**: Key indicators including active projects, completed tasks, velocity, and open pull requests.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build & Typecheck

```bash
npm run build
```
